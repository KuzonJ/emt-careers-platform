# EMT Careers Platform

A front-end web project created for Web Programming and Design. EMT is a career/recruitment platform concept designed to help students, new graduates, and young professionals improve how they present their resumes and explore career opportunities.

## Live Demo

https://kuzonj.github.io/emt-careers-platform/

## Features

- Multi-page responsive website
- Resume assistance concept
- Pricing page with plan options
- About and contact pages
- Clean navigation and modern layout
- JavaScript-powered interactive elements

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages

I contributed to the front-end development of the project, including page layout, styling, pricing/about page work, and improving the overall user experience.
